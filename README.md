чтобы отслеживать файлы в git  надо ввести cd (путь к файлу иои отслеживаемой папке) нажать  enter
и ввести git init и нажать enter (отслеживает изменения в папках и проектах в указанном пути и не выкладывает их в сеть).
Чтобы прицепить локальный репозиторий к репозиторию в сети надо ввести git remote add origin (ссылка к репозиторию в сети).
Чтобы создать копию чьего-то репозитория у себя в пк нужно ввести cd (путь куда копия сохранится) enter
а теперь git clone (ссылка на сетевой репозиторий в котором лежат копируемые файлы и папки).
git status выведет инфу о всех файлах, которые были изменены, но не сохранены
git add (имена папок или файлов, которые нужно ПОДГОТОВИТЬ К сохранению из текушего пути или просто поставить точку. Это ПОДГОТОВИТ
сохрани. все файлы в текущем пути.
git commit -m(типо с англ message) 'информация о изменении файла'. Данная комманда сохранит подготовленные к сохранению файлы.
git log выводит информацию о всех сохранениях файла с информацией о изменении файла (которую вводили в git commit)
Также на строке commit будут ключи ко всем изменениям в файла
git checkout (ключ сохранения). Вернет к указанной точке сохранения
git push (имя репозитория) (ветка изменений). отправляет в сетевой репозиторий выбранную ветку изменений
git pull (имя репозитория) (ветка) (копирует последнюю версию и предыдущие версии файла)
git branch (показывает) все существующие ветки изменений. Имя основной ветки master
git branch (имя создаваемой ветки изменений). создает ветку изменений, но не переводит на нее
git checkout (имя ветки). переводит на определенную ветку изменний
git merge (имя ветки с которой будет соединяться текущая ветка)
git rebase (имя ветки) переносит переносит все точки сохранения из указанной ветки в ту, в которой пользователь находится
